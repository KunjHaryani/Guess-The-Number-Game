# Multiplayer Number Guessing Game in C

A simple multiplayer number guessing game developed in C language using functions, loops, conditional statements, and random number generation.

## Features
- Multiplayer support
- Random number generation
- Score tracking
- User-friendly console interface

## Technologies Used
- C Language
- stdio.h
- stdlib.h
- time.h

## How the Game Works
1. The program generates two random numbers.
2. Players take turns playing the game.
3. Player 2 has to take less turns for guessing their number.
4. The program gives hints like:
   - Correct Number is Too High
   - Correct Number is Too Low
5. The player who guesses correctly in less turns wins the round.

## Concepts Used
- Functions
- Loops
- Conditional Statements
- Random Numbers using `rand()`
- `srand(time(0))`
- Variables and Arrays
