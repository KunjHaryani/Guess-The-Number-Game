# Multiplayer Number Guessing Game in C

A simple multiplayer number guessing game developed in C language using functions, loops, conditional statements, and random number generation.

## Features
- Multiplayer support
- Random number generation
- Score tracking
- User-friendly console interface
- Replay option

## Technologies Used
- C Language
- stdio.h
- stdlib.h
- time.h

## How the Game Works
1. The program generates a random number.
2. Players take turns guessing the number.
3. The program gives hints like:
   - Too High
   - Too Low
4. The player who guesses correctly wins the round.

## Concepts Used
- Functions
- Loops
- Conditional Statements
- Random Numbers using `rand()`
- `srand(time(0))`
- Variables and Arrays
